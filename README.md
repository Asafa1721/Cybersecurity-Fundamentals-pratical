# Cybersecurity Portfolio — Workbook 1: Introduction to Cybersecurity

## Summary
This repository documents my completion of Workbook 1 of the Cybersecurity Academy Foundations Track. It includes a full risk assessment for a fictional retail company (Beacon Retail Co.), applying the CIA Triad, a risk register, and practical security recommendations — the final deliverable from the workbook's capstone project.

## Skills Demonstrated
- Risk assessment and risk register construction (Asset / Threat / Likelihood / Impact / Mitigation)
- Applying the CIA Triad (Confidentiality, Integrity, Availability) to real assets
- Security writing for both technical and non-technical audiences
- Threat identification (malware, phishing, ransomware, DDoS, insider threats, etc.)
- Mapping security tools to realistic use cases (Nmap, Wireshark, Nessus, Splunk, and others)

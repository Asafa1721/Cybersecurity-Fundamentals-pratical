# Notes: Common Threats

Quick reference on the ten threat categories from Workbook 1, Module 03

| Threat | What it actually does |
|--------|------------------------|
| Malware | Umbrella term for any software built to harm a device, steal data, or give an attacker control without permission. |
| Viruses | Malware that attaches to a legitimate file and only spreads when a human runs it. |
| Worms | Malware that spreads on its own across a network, no human interaction needed. |
| Trojans | Malware disguised as legitimate software; opens a hidden backdoor once installed. |
| Ransomware | Encrypts a victim's files and demands payment for the decryption key. |
| Phishing | Fake emails/texts/websites impersonating a trusted source to steal credentials. |
| Social Engineering | Manipulates human psychology (trust, fear, urgency) instead of breaking technology. |
| Insider Threats | Misuse of legitimate access by an employee, contractor, or partner — intentional or accidental. |
| Password Attacks | Guessing or stealing credentials: brute force, leaked password lists, credential stuffing. |
| DDoS Attacks | Floods a target with traffic from many machines at once to make it unavailable. |

## Why this matters for the risk register
Every row in `final-project/risk-register.csv` maps back to one of these categories. Naming the *type* of threat (not just "hackers") is what makes a risk register useful — it points directly to the right mitigation.
